
# Remy Aisha Hijabis Website

## Project Overview

This project is an informational website developed for Remy Aisha Hijabies, a modest fashion boutique located in Kampala, Uganda.

The website provides customers with information about the business, its products, services, location and contact details.

## Problem Statement

Customers previously experienced difficulties finding the boutique's location, products, prices and contact information in one place. The website was developed to make this information easier to access.

## Project Objectives

- To provide information about the boutique.
- To display available products and prices.
- To help customers locate the shop.
- To provide easy communication through WhatsApp.
- To showcase products through images and videos.

## Technologies Used

- HTML5 – website structure.
- CSS3 – website styling and layout.
- JavaScript – handling the customer enquiry form.
- GitHub – source code storage and version control.
- GitHub Pages – website hosting.
